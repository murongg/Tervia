# Repository instructions

## Screenshots and visual artifacts

- Take screenshots only when explicitly requested or needed for visual debugging or verification.
- Save temporary screenshots, recordings, and visual-check artifacts in a system temporary directory outside this repository.
- Commit screenshots only when the user explicitly requests repository storage or when they are necessary illustrations referenced by maintained documentation. Keep the smallest useful set; avoid redundant states and light/dark variants unless they explain a meaningful difference.
- Attach useful visual evidence to the PR instead of committing verification artifacts solely as proof of testing.
- Before committing, review the diff for accidental visual artifacts and remove temporary or unreferenced screenshots introduced by the task.
